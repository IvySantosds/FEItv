## Descrição

O FEItv é uma plataforma desktop desenvolvida em Java com o objetivo de gerenciar e compartilhar informações sobre conteúdos audiovisuais, como filmes e séries. Inspirado em plataformas de streaming, o sistema oferece funcionalidades de interação entre usuários e organização personalizada de conteúdos.

A aplicação permite cadastro e autenticação de usuários, pesquisa de vídeos, sistema de curtidas, criação de playlists e gerenciamento de favoritos. Além disso, possui um módulo administrativo responsável pelo controle do catálogo de vídeos, visualização de usuários cadastrados e exibição de métricas da plataforma.

O projeto foi desenvolvido utilizando arquitetura MVC (Model-View-Controller), interface gráfica com Swing, persistência de dados em PostgreSQL e comunicação com o banco através de JDBC, garantindo organização, manutenção facilitada e escalabilidade do sistema.
